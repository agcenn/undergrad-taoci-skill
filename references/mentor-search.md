# Mentor Search

Use this only when the user wants to contact a lab/department but has not chosen a professor.

## Goal

Find a small, defensible shortlist that improves outreach quality. Do not produce a long directory dump.

## Workflow

1. Identify the target university/department/lab and the user's broad research interests.
2. Start from official faculty/lab pages whenever possible.
3. Build an initial pool of roughly 6–12 plausible mentors.
4. Check recent research activity and current topic fit.
5. Look for public undergraduate participation evidence.
6. Rank 3–5 mentors for deeper analysis.

## Evidence priority

Strong evidence:
- official university or faculty page
- lab page with current projects or people
- professor homepage
- recent publication list / DBLP / Scholar profile
- explicit undergraduate research or recruiting page

Weak evidence:
- stale aggregators
- search snippets without page inspection
- old conference bios
- third-party summaries with no primary source

## Output

Prefer a compact table:

| Mentor | Recent focus | Fit with student | Undergraduate evidence | Uncertainty | Next action |
|---|---|---|---|---|---|

Then identify the top 1–3 people to analyze further.

## Rules

- Do not call someone “undergraduate-friendly” merely because the lab has many students.
- Do not infer active recruiting from a research match.
- Do not use the score as an acceptance probability.
- If the user already has one target mentor, skip search and use Mentor Analysis.
