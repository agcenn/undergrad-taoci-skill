# Mentor Analysis

Use this when evaluating one or more known professors before writing outreach.

## Four dimensions

### 1. Research fit — 40%

Ask whether the student's current interests, courses, projects, and skills overlap with the mentor's **recent** research questions.

Suggested interpretation:
- 85–100: direct overlap in problem + method/stack
- 70–84: clear overlap with a realistic transition path
- 50–69: adjacent direction; outreach can work if framed carefully
- below 50: weak fit; do not manufacture a connection

### 2. Experience fit — 25%

Use undergraduate-appropriate evidence:
- course projects
- GitHub / personal projects
- competitions
- research assistant work
- engineering implementation
- relevant coursework
- reproducibility / experimental work

Do not penalize a student merely for having no publication.

### 3. Undergraduate participation evidence — 20%

Evidence examples:
- professor explicitly welcomes undergraduates
- lab member page lists undergraduates
- university URP / independent study / summer research supervised by the professor
- public undergraduate co-authorship or project participation

If evidence is absent, label it **unknown** rather than assigning a confident high score.

### 4. Recent continuity — 15%

Check whether the target topic remains active in roughly the last 2–3 years.

## Score

If all dimensions have usable evidence:

`score = 0.40*research_fit + 0.25*experience_fit + 0.20*undergrad_evidence + 0.15*continuity`

If undergraduate evidence is unknown, do not fake a number. Either:
- report the component as unknown and make the total explicitly provisional, or
- omit the total and rank qualitatively.

## Research direction quick view

For each top mentor, explain in undergraduate-friendly language:
- what the group studies
- why the problem matters
- common methods / stack
- what has been active recently
- which student experience is the best entry point
- optionally, 1–3 things to read before emailing

## Key output: outreach angle

Every analysis should end with one specific sentence:

> Best outreach angle: connect **[student evidence]** to **[mentor research anchor]** because **[credible reason]**.
