# Research Readiness Gap

This module supports outreach writing. It is not a full research roadmap.

## Questions to answer

1. What can the student already claim truthfully?
2. Which experiences transfer to the mentor's research even if the topic differs?
3. Which important skills are currently missing?
4. What should the email emphasize or avoid?
5. Is there one small preparation step worth doing before sending?

## Format

```text
Direct evidence:
- ...

Transferable evidence:
- ...

Current gaps:
- ...

Use in email:
- emphasize ...
- describe ... as interest/learning goal, not existing expertise
- do not claim ...

Optional pre-send prep:
- one or two small actions only
```

## Decision guidance

### Ready now
There is at least one credible bridge between the student's background and mentor's current work. Draft immediately.

### Ready with careful framing
The student has adjacent skills but not direct research experience. Draft now, explicitly frame missing skills as learning goals.

### Weak fit
There is no meaningful bridge. Tell the user this and, if useful, suggest a different mentor or one small project/read before outreach.

## Anti-overclaim rule

Convert gaps into learning intent:

Bad:
> I have extensive experience in LLM inference optimization.

Better when the student only has systems/kernel experience:
> My systems and kernel-development experience has made me interested in how low-level optimization affects LLM inference efficiency.
